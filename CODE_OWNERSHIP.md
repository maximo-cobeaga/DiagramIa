# Código y recursos

El código de este paquete es la base del proyecto Diagramia entregada para su desarrollo. No se ha elegido una licencia pública de distribución ni se publicó un repositorio. Elegir la licencia antes de abrirlo a terceros.

Fuentes Manrope e IBM Plex Mono: SIL Open Font License; archivos de licencia junto a las fuentes. Dependencias externas: sus licencias están en cada paquete instalado; package-lock.json fija las versiones. Verificar las licencias de cualquier nuevo motor de canvas, librería o asset antes de adoptarlo.

No contiene credenciales de Sites, tokens, configuraciones privadas ni conexiones empresariales. La landing es una copia estática portable, sin el manifiesto del servicio de hosting ni su historial Git.
